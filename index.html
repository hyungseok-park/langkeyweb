Features

One Key. One Language. Always.

🌐
Up to 4 Languages
Map Left ⇧, Right ⇧, Left ⌃, and Right ⌃ to any 4 input sources.
🎯
No More Toggling
Each key is dedicated. Tap Right ⇧ — it's always Korean. No guessing, no surprises.
👁
Instant Visual Feedback
A brief overlay shows the flag and language name every time you switch. You always know where you are.
⌨️
Works with Your Shortcuts
Only triggers on a clean quick tap (< 0.3s). Cmd+Shift, Ctrl+C — all your shortcuts still work perfectly.
Setup

How It Works

1
Map Your Keys
Open LangKey from the menu bar. Assign each modifier key (up to 4) to an input language.
L-Shift ⇧🇺🇸 English
R-Shift ⇧🇰🇷 한국어
L-Ctrl ⌃🇯🇵 日本語
R-Ctrl ⌃🇨🇳 中文
2
Tap to Switch
Tap the modifier key for the language you need. A brief overlay confirms which language you're now in.
R-Shift ⇧ →

3
Type Confidently
You know exactly which language you're in. No more wrong-language surprises.
